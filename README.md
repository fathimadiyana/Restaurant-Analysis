# Cognifyz Restaurant Analysis Project

## Internship
Cognifyz Technologies - Machine Learning Internship

## Project Overview
This project contains four machine learning and data analysis tasks based on restaurant data. The project includes regression, recommendation system, classification, and location-based analysis.

## Tasks Completed

### Task 1: Restaurant Rating Prediction
Built a regression model to predict the aggregate rating of restaurants using features such as average cost, price range, and votes.

### Task 2: Restaurant Recommendation System
Created a content-based recommendation system that recommends restaurants based on user preferences such as city, cuisine, price range, and rating.

### Task 3: Cuisine Classification
Developed a classification model to classify restaurants based on cuisine using machine learning techniques.

### Task 4: Location-Based Analysis
Performed geographical analysis of restaurants using latitude, longitude, city, locality, ratings, and price range.

## Dataset
Restaurant dataset provided for Cognifyz Technologies internship.
